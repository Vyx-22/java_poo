# Java et POO

Mes notes pour apprendre Java et la programmation orientée objet, rédigées en suivant la série YouTube « Apprenez le Java et la Programmation Orientée Objet » de JirAWS, dans le cadre de ma L2 en cybersécurité.

Chaque note suit le même modèle : la définition, une explication simple, des exemples de code commentés, puis les règles et les pièges à retenir.

## Mise en pratique

Pour appliquer ces notions, j'ai réalisé un [jeu de devinette de mots](https://github.com/Vyx-22/jeu_devinette) pour deux joueurs, en version console et avec interface graphique. Il utilise l'encapsulation, les collections, la lecture de fichiers, les exceptions et l'héritage.
